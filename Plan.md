## 🎯 EXECUTION PLAN

### Phase 1.1: Data Standardization
*   **Files to Touch:** `packages/schemas/events.py`
*   **Action:** Flesh out the Pydantic models. Ensure they can handle missing data gracefully (e.g., if an agent makes an API call but doesn't use `<thinking>` tags, or if an OS command doesn't have an identifiable parent process).
*   **Outcome:** A robust set of data models that both the network proxy and OS monitor can import and instantiate.

### Phase 1.2: Network & Reasoning Interception (Layer 1)
*   **Files to Touch:** `apps/agent/src/interceptors/network_proxy.py`
*   **Action:** 
    1.  Parse outgoing `flow.request` for system prompts and user inputs aimed at Anthropic/OpenAI APIs.
    2.  Parse incoming `flow.response` JSON.
    3.  Write regex/extraction logic to pull text out of `<thinking>`, `<thought>` tags, or tool call arguments. 
    4.  Map the extracted data to the `NetworkIntercept` schema.
*   **Outcome:** A working `mitmproxy` script that prints highly structured logs to the terminal showing *what* the agent was asked and *how* it planned to solve it.

### Phase 1.3: OS Terminal Monitoring (Layer 2)
*   **Files to Touch:** `apps/agent/src/interceptors/os_monitor.py`
*   **Action:**
    1.  Write a non-blocking generator to tail `/var/log/audit/audit.log`.
    2.  Parse lines containing `type=EXECVE`.
    3.  Extract the executable (`exe=`), arguments (`a0=`, `a1=`), and user info.
    4.  Filter for commands likely executed by agents (ignore background system noise).
    5.  Map to the `TerminalAction` schema.
*   **Outcome:** A script that successfully prints every terminal command executed by the AI (or the user) in real-time.

### Phase 1.4: Local Buffering & Correlation (Layer 3)
*   **Files to Touch:** `apps/agent/src/core/buffer.py`, `apps/agent/src/main.py`
*   **Action:**
    1.  Create an asynchronous queue or local SQLite instance in `buffer.py` to store the schemas generated by Phase 1.2 and 1.3.
    2.  Update `main.py` to ensure both the proxy and the OS monitor are pushing to this shared buffer.
*   **Outcome:** A single, unified stream of data showing the agent's internal reasoning immediately followed by the actual terminal commands it executed.
